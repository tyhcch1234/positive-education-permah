# PERMAH 正向教育 · 中學生版

一個單頁靜態網站，用 Seligman 的 PERMA 幸福理論（加上 Health 成為 PERMAH）整理正向教育的六大元素，並附上香港中學生可立即使用的例子。

## 內容

- **六大元素**：正向情緒、投入、人際關係、意義、成就、健康。每個元素包含定義、4 個中學生應用例子、1 個真實人物／新聞見證（附出處連結）、1 個「今日就做」行動。
- **真實見證**：江旻憓、谷愛凌、李慧詩與沈金康、余翠怡、張家朗、鄭秀文。所有引述均取自公開報道或官方文章，並在頁面標明來源與轉述性質。
- **1 分鐘自我檢視**：六條滑桿即時生成 SVG 雷達圖與針對性建議。
- **一週實踐表**：每天一個元素、一個 10–20 分鐘的動作。
- **破解迷思**與**求助資源**（香港 24 小時熱線）。

## 結構

```
index.html   頁面內容
styles.css   樣式（含響應式與列印樣式）
app.js       分頁、雷達圖、導覽與進場動畫
```

無建置步驟、無框架、無外部 JS 依賴。只有 Google Fonts 一個外部資源（Noto Serif TC / Noto Sans TC / Inter），載入失敗時會回落到系統中文字體。

## 本機預覽

直接用瀏覽器打開 `index.html`，或：

```bash
python3 -m http.server 8000
```

## 備註

- 頁面為教育用途整理，不構成心理或醫療診斷。
- 數據來自各調查公布之受訪樣本，不能直接推論全港所有學生。
- 人物引述保留原文語句；部分為媒體轉述而非逐字官方文稿，已在對應位置標示。
